# 斑马资源库

斑马资源库是一款 Windows 桌面工具，用于整理当前账号有权访问的斑马课程资源。它可以浏览课程和专辑，按课程目录归类音视频，并在下载前选择清晰度与语言。

当前版本为 `0.1.0`，仍处于开发和验收阶段，暂不提供正式发行包。

版本变化请查看 [更新日志](CHANGELOG.md)。

## 主要功能

- 分别登录斑马百科、斑马口语和斑马 AI 学。
- 浏览课程包、专辑、课节和可下载资源。
- 按“专辑 / 子课程”自动建立下载目录。
- 按课程顺序为文件添加序号，方便播放器正确排序。
- 将同一视频的多个清晰度合并为一个课程视频展示。
- 支持多选 `4K`、`1080P`、`720P` 和标清版本。
- 支持选择中文、英文或全部语言版本。
- 支持批量解析专辑，也可以只解析资源而不立即下载。
- 显示专辑进度、下载状态、失败原因和已写入大小。
- 支持停止全部任务、重试失败任务和打开下载目录。
- 支持预览可直接访问的图片、音频以及已下载的视频。

课程界面的装饰图片、视频时间轴截图、互动模型、动画运行包、奖励提示音等内容会被自动排除，资源列表只保留适合独立查看和保存的课程内容。

## 使用前准备

### 系统要求

- Windows 10 或 Windows 11
- 可正常访问课程服务的网络环境
- 已购买或已解锁相应课程的斑马账号

正式安装包会随应用携带视频下载、封装、解密和播放校验所需的 FFmpeg 与 Bento4 工具，普通用户无需单独安装依赖或配置 `PATH`。

## 基本使用

1. 启动应用并选择产品。
2. 使用手机号和验证码登录。
3. 进入课程包或专辑，查看课程和学习任务。
4. 在右侧选择保存位置、并发数、视频清晰度和视频语言。
5. 勾选需要的课程资源或专辑。
6. 根据需要选择：
   - **仅解析所选专辑**：读取并展示资源，不下载文件。
   - **下载所选专辑**：解析后按专辑逐个下载。
   - **下载所选内容**：下载当前资源列表中已经勾选的内容。
7. 下载完成后，点击“打开下载文件夹”查看结果。

面包屑中的中间目录可以点击返回。返回上一级时，应用会恢复该层已经加载的资源列表。

## 下载目录和文件名

资源会按照课程结构保存，例如：

```text
下载目录/
└─ 认识月球/
   ├─ 001_认识月球_中文_1080P_资源标识.mp4
   └─ 001_认识月球_英文_资源标识.mp4
```

文件名中的字段含义：

- `001`：课程或剧集顺序。
- `中文 / 英文`：视频语言。
- `4K / 1080P / 720P / 标清`：视频清晰度。
- 末尾资源标识：用于避免同名文件互相覆盖。

同一课程的多个清晰度在界面中只计算为一个视频，但选择多个清晰度时会分别下载对应文件。

## 下载和停止任务

- 多个专辑会按照选中顺序逐个处理。
- 当前专辑内部按照右侧设置的并发数下载，视频优先。
- 点击“停止全部下载”后，应用会终止网络请求、媒体处理进程和排队任务。
- 未完成的临时文件可能被保留，用于下次重试时继续下载。
- 下载失败后，可以使用“重试全部失败/中断”。

## 常见问题

### 视频下载后无法播放

在应用中重试失败任务。正式安装包已包含媒体处理工具，应用只会将通过完整性和播放校验的视频标记为下载完成；如果仍然失败，请保留界面中的失败原因和开发日志以便排查。

### 停止后界面仍显示已写入大小

“已写入大小”表示本次任务停止前已经写入的数量，不代表仍在继续下载。停止按钮会保持处理中状态，直到网络流和媒体进程全部退出。

### 为什么资源数量比课程页面少

应用会合并同一视频的多种清晰度，并过滤不能独立使用的界面素材和互动运行资源，因此界面数量按实际课程内容计算。

### 为什么没有看到英文版本

只有课程本身提供英文视频时才会显示英文版本。请在右侧“视频语言”中选择“英文”或“全部语言”。

### 只想查看资源，不想立即下载

先选择一个或多个专辑，再点击“仅解析所选专辑”。解析完成后可以检查资源名称、语言和清晰度，再决定是否下载。

## 登录信息与隐私

- 手机号和验证码仅用于登录请求。
- 会话 Cookie 使用 Windows DPAPI 加密后保存在当前用户的应用数据目录中，只能由同一 Windows 用户解密。
- `sessions.json` 仅保存非敏感的登录状态信息，不再明文保存 Cookie；旧版本明文 Cookie 会在首次启动时自动迁移。
- 点击“退出登录”会清除对应产品的本地登录状态。
- 请勿将本机应用数据目录中的会话文件分享给他人。

## 本地运行

参与测试或开发时，需要安装 Node.js 22、pnpm 10 和稳定版 Rust 工具链。

开发模式允许从系统 `PATH` 使用 FFmpeg 与 Bento4。生成 Windows 安装包时请统一执行 `pnpm bundle:windows`，该命令会自动准备并打包运行时工具，不能直接绕过该命令发布。

```powershell
pnpm install --frozen-lockfile
pnpm tauri dev
```

提交代码前可以运行：

```powershell
pnpm format
pnpm format:check
pnpm build
pnpm test:unit
pnpm test:e2e
cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets --all-features -- -D warnings
cargo test --locked --manifest-path src-tauri/Cargo.toml --all-targets
```

PowerShell 格式化依赖 `PSScriptAnalyzer`，首次使用可执行 `Install-Module PSScriptAnalyzer -Scope CurrentUser`。GitHub Actions 会在每次推送和拉取请求时执行构建、全仓格式检查、前端单元测试、浏览器端到端测试、Rust 静态检查和单元测试。该流程不会生成或发布安装包。
